# Memory

- The runtime harness lives at `$env:USERPROFILE\.codex`.
- This repository is intended to become the GitHub-ready source of truth.
- The previous `<workspace>\Harness` folder is a legacy
  reference package and includes cross-runtime material that is no longer
  the active architecture.
- The active harness intentionally keeps Figma and other domain-specific
  capabilities outside the generic core unless needed for a project.
