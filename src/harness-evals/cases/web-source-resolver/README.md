# Web Source Resolver Eval

This deterministic eval verifies the global URL-intake layer independently of
any project:

- ordinary body fallback for a static page without article/main containers
- client-rendered shell classification
- Web-mode schema, page metadata, content roots, and visible-text evidence
- article, documentation, JSON, XML feed, plain-text, PDF, and image routing
- content-type hints plus content-signature and extension detection
- explicit network opt-in and private-network blocking through the shared core

Fixtures are synthetic and contain no copied web content or runtime state.
Optional live URLs are saved only under the system temp directory.
